<div align="center">

### 📦 LedgerStock — <sub>em desenvolvimento</sub>

Sistema de gestão de estoque (Django) para pequeno comércio. Resolve os três problemas mais comuns de controle manual: **estoque fantasma**, **falta de rastreabilidade** e **decisão de compra às cegas** — com modelo Produto/Movimentação auditável e concorrência segura.
